# TrailRunCoach 示範

一位**虛構跑者**一年的訓練資料（程式產生，跟任何真人無關），用來試用：

- **排課表**：拖曳課程、課表偏好、每趟的步驟和目標功率
- **賽事計算機**：內建路跑半馬、越野 50K、百岳 3 日，也能上傳 GPX
- **週期規劃**：賽事、基礎／強化／專項／減量期

你的修改只存在你的瀏覽器（cookie），24 小時後自動清除；「重設示範」可以馬上回到原始資料。
同步手錶、推送課表、分享連結、AI 在示範裡是關閉的。

This Space runs the demo instance of TrailRunCoach with a synthetic athlete
only. Edits live in a per-visitor sandbox for 24 hours.
