# Contributing

Thanks for wanting to help. Bug reports, ideas and pull requests are welcome.

## Before you open a pull request

TrailRunCoach is published under the [PolyForm Noncommercial License 1.0.0](LICENSE), and the
author also licenses it on commercial terms. To be able to do both with your work, every
contribution needs the [Contributor License Agreement](CLA.md).

- You keep the copyright in your contribution; the agreement is a license, not a transfer.
- It lets the author include your contribution in the noncommercial release and in
  commercial licenses, now and in the future.

Agree to it by adding this line to your pull-request description (the template has a
checkbox for it):

> I have read CLA.md (version 1.0) and agree to its terms for this and all my future
> contributions to TrailRunCoach.

Pull requests without it can't be merged. Bug reports and issues don't need it unless they
include code you want added.

## Working on the code

- Setup, running and tests: see [README.md](README.md).
- Keep changes focused; one topic per pull request.
- Add or update tests for behaviour changes and run the test suite before you open the
  pull request.
- If any part of your change comes from somewhere else (another project, a paper's
  published code, a spreadsheet), say where and under which license.
